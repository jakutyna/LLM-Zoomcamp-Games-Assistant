# LLM-Zoomcamp-Games-Assistant

- project for LLM Zoomcamp 2026
- game assistant to ask questions about games from Metacritic ranking (limited to 300 games)
- the anwsers are grounded with the data for each game

Ranking source: [https://www.metacritic.com/browse/game/all/all/all-time/userscore/](https://www.metacritic.com/browse/game/all/all/all-time/userscore/).

## Prerequisites

- uv
- docker
- OpenAI account

Install `uv` (Mac/Linux):
```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

OpenAI API key (`.env`):

```sh
OPENAI_API_KEY=sk-<YOUR_KEY_HERE>
```

Note: Make sure `.env` is included in `.gitignore` file so you never accidentally commit your key.


## Data

The titles of 300 top games in the Metacritic ranking was pulled into [data/top_games.csv](data/top_games.csv) by prompting Github Copilot. Then the details for each games was generated with a script [data/generate_data.py](data/generate_data.py) that calls OpenAI API with a templated prompt for each game. The calls are done asynchronously with a [`concurrent.futures`](https://docs.python.org/3/library/concurrent.futures.html) module. The respones are returned in a proper format - a `Game` pydantic model defined in [data/game_model.py](data/game_model.py).

Game details can be re-generated by running (the script runs for more than 1 minute):
```sh
uv run data/generate_data.py
```

This can be also tested on a smaller subset of data with [data/generate_data.ipynb](data/generate_data.ipynb) notebook.
